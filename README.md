🚀 راه‌اندازی پروژه
ابتدا مخزن پروژه را دریافت کنید:
git clone https://github.com/hoshivaraibot/-.git

وارد پوشه پروژه شوید:
cd -

کتابخانه‌های موردنیاز را نصب کنید:
pip install -r requirements.txt

🔐 متغیرهای محیطی
برای اجرای ربات، متغیرهای محیطی موردنیاز را در محیط میزبانی تنظیم کنید:
BOT_TOKEN
GEMINI_API_KEY
WEBHOOK_SECRET
CLOUDFLARE_ACCOUNT_ID
CLOUDFLARE_API_TOKEN
همچنین آدرس سرویس میزبانی از طریق RENDER_EXTERNAL_URL قابل تنظیم است.
▶️ اجرای ربات
python bot.py
