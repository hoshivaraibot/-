
# 💙 Hoshivar AI

دستیار هوش مصنوعی هشیوار؛ یک ربات فارسی‌زبان در تلگرام.

## ✨ امکانات
- گفتگوی هوشمند فارسی
- پاسخ‌گویی به سؤالات کاربران
- حافظه موقت گفتگو
- منوی دکمه‌ای تلگرام
- مدیریت کاربران
- اتصال به موتور هوش مصنوعی

## 🛠 تکنولوژی‌ها
- Python
- pyTelegramBotAPI
- Requests
- Render

## 🚀 راه‌اندازی
1. نصب کتابخانه‌ها:
   pip install -r requirements.txt

2. تنظیم متغیرهای محیطی در Render:
   - BOT_TOKEN
   - GEMINI_API_KEY
   - GROK_API_KEY
   - WEBHOOK_SECRET

3. اجرای برنامه:
   python bot.py
